this directory. The API reference is generated from the source and published
at <https://docs.rs/sphinx-ultra> and <https://salioglu.github.io/sphinx-ultra/>.

## Conventions

- A status claim in any document must be true of `sphinx-ultra build` at
  `main`, with evidence. If a change moves a subsystem's status, update
  IMPLEMENTATION_STATUS.md and ROADMAP.md §2 in the same pull request.
- New implementation plans go to `plans/` with a `YYYY-MM-DD-` prefix.
- The GitHub Pages site is built by `scripts/dev.sh pages` into
  `target/pages`; nothing generated is committed under `docs/`.
