# Sphinx Feature-Surface Inventory (for sphinx-ultra parity)

**Baseline verified against:** Sphinx **9.1.x** (9.1.0 released 2025-12-31; 9.1.1 in development as of 2026-08). Requires Python ≥3.12, Docutils ≥0.21. Notable recent additions relevant to parity: `theme.toml` (7.3), `confval` directive + `.jinja` template suffix (7.4), `--fresh-env`/CLI modernization, `add_static_dir()` (9.1), dashed directive aliases like `version-added` (9.x), `docurls` key in searchindex. Where "verified" is noted below, the item was checked against sphinx-doc.org master docs in August 2026.

Legend: **[MUST]** = required for a credible "drop-in Sphinx replacement" claim · **[SHOULD]** = required by most real projects · **[NICHE]** = long-tail.

---

## 1. Build model — **[MUST]** overall

- **Application lifecycle** [MUST]: `Sphinx(srcdir, confdir, outdir, doctreedir, buildername)` → load conf.py → init extensions (each ext's `setup(app)`) → init builder → **read phase** (parse changed docs → doctrees) → **write phase** (resolve + render). Two-phase separation is architectural bedrock; extensions assume it.
- **Core events, in firing order** [MUST — verified list]: `config-inited(app, config)` → `builder-inited(app)` → `env-get-outdated(app, env, added, changed, removed)` → `env-before-read-docs(app, env, docnames)` → per-doc: `env-purge-doc` → `source-read(app, docname, content)` → `include-read(app, relative_path, parent_docname, content)` → `object-description-transform(app, domain, objtype, contentnode)` → `doctree-read(app, doctree)` → `env-merge-info(app, env, docnames, other)` (parallel only) → `env-updated(app, env)` → `env-get-updated` → `env-check-consistency` → `write-started(app, builder)` → `doctree-resolved(app, doctree, docname)` → `missing-reference(app, env, node, contnode)` / `warn-missing-reference(app, domain, node)` → `html-page-context(app, pagename, templatename, context, doctree)` → `html-collect-pages(app)` → `linkcheck-process-uri(app, uri)` → `build-finished(app, exception)`. Event emission with priority-ordered callbacks (`connect(event, cb, priority=500)`), `emit()` vs `emit_firstresult()`. Extensions live and die by these hooks; parity means emitting equivalents at equivalent times.
- **BuildEnvironment** [MUST]: the cross-document state store — titles, TOCs, toctree structure, labels, domain data dicts (`env.domaindata[...]`), dependencies per doc, images, downloads, metadata (`:orphan:`, `:nocomments:`, `:tocdepth:` file-wide metadata fields). All cross-referencing resolves against it.
- **Pickled env caching** [SHOULD]: `environment.pickle` + one pickled doctree per document in `doctreedir` (`.doctree` files). Enables incremental rebuild; also `env_version` per extension invalidates cache on ext schema change. A Rust reimpl needs an equivalent serialized cache; byte-compatible pickle is NOT required (nothing external consumes it except `sphinxcontrib-serializinghtml` consumers), but cache-invalidation semantics are.
- **Incremental/outdated logic** [MUST]: a doc is outdated if: source mtime > doctree mtime, any dependency (included files, literalinclude'd files, images, templates via `note_dependency`) changed, config values with `rebuild='env'` changed (full re-read), extension `env_version` bumped, or an `env-get-outdated` handler adds it. Removed/added docs trigger toctree-parents re-read. Docs depending on changed targets re-resolve at write time (`env-get-updated`). `-E` / `--fresh-env` forces full rebuild; `-a` forces write-all.
- **Parallel read/write** [SHOULD]: `-j N`/`-j auto`; read phase forks workers, each returns a partial env merged via `env-merge-info`; write phase parallelizes rendering. Gated on every active extension declaring `parallel_read_safe`/`parallel_write_safe`. Rust reimpl can trivially beat this — but must keep the ext-metadata gate semantics if it hosts Python extensions.
- **conf.py execution model** [MUST]: conf.py is **executed as arbitrary Python** in `confdir` (cwd set, `__file__` set), with a `tags` object injected (`tags.has()`, `tags.add()`, and since 8.1 `tags` is iterable/set-like); module-level names matching registered config values become config. `-D name=value` / `-A name=value` overrides, `-t tag` sets tags. This is the single hardest parity point for a Rust tool: real projects compute config in Python (sys.path hacking for autodoc, dynamic version from package metadata, calling `setup(app)` defined inside conf.py for inline extensions). Options: embed Python, subprocess a Python evaluator, or support a declarative subset + escape hatch. `conf.py` may also define `setup(app)` — an inline extension [MUST for compat].
- **CLI surface** [MUST]: `sphinx-build -b <builder> [-M make-mode] -j -E -a -t -D -A -n (nitpicky) -W (warnings-as-errors) -q -v --keep-going -w warnfile -c confdir -d doctreedir`; `sphinx-quickstart`; `sphinx-apidoc`; `sphinx-autogen`. `-M` make-mode entry point is what Makefiles from quickstart use.

## 7. Cross-referencing machinery — **[MUST]**

- **std labels**: explicit `.. _label:` before section/figure/table/code-block → `ref` with captioned-target title inference; arbitrary-location labels need explicit titles; duplicate-label warnings. `ref` vs `numref` semantics. **[MUST]**
- **autosectionlabel** (`sphinx.ext.autosectionlabel`): auto-labels every section title (`autosectionlabel_prefix_document`, `autosectionlabel_maxdepth`); dup-warning behavior. **[SHOULD]**
- **intersphinx** [MUST — verified]: `intersphinx_mapping = {name: (target_uri, inventory_or_None_or_tuple_of_fallbacks)}`; fetch with cache (`intersphinx_cache_limit` days, default 5; `intersphinx_timeout`); `intersphinx_disabled_reftypes` (default `['std:doc']`, supports `*` and `domain:*`); `intersphinx_resolve_self`; `:external:` role family (`:external:py:class:`, `:external+invname:reftype:`); resolution order: local first, then inventories (unless `:external:`); old un-prefixed fallback resolution.
- **objects.inv v2 format** [MUST — verified byte-level]: 4 plain-text header lines: `# Sphinx inventory version 2`, `# Project: <name>`, `# Version: <ver>`, `# The remainder of this file is compressed using zlib.` — then zlib-compressed payload of lines: `{name} {domain}:{role} {priority} {uri} {dispname}`; priority ∈ {-1,0,1,2} (1 default, -1 hidden from `any`-search); `$` at URI end expands to `name`; dispname `-` means same-as-name; names may contain spaces; must both **emit** (every HTML build writes `objects.inv`) and **consume**.
